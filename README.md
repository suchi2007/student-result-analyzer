# Student Result Analyzer

## Project Description
Student Result Analyzer is a Python-based project that analyzes student examination results using CSV data.

## Technologies Used
- Python
- CSV

## Features
- Reads student details from a CSV file.
- Analyzes student marks.
- Calculates total and average marks.
- Displays student performance.

## Project Files
- student-result-analyzer.py
- results.csv
